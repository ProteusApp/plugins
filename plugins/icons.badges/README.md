# Letter Badges

A file icon pack for Proteus. Each kind of file gets a small badge of letters, such as `TS`, `RS`, `LU` or `MD`, and pictures, sounds and archives get an icon. The badges use the color theme's syntax colors, so they change with the theme: the same `RS` is orange in one theme and pink in another.

Choose it with **View > Choose File Icons**, where the arrow keys preview each pack before you pick it, or set `icon_pack` to `badges` in the settings. The Explorer, the Code Editor's file tree and the editor tabs all show it.

It adds its badges as file associations of the kind `icon`, so it runs no code while you work, and it asks for no permissions. It needs a Proteus with the `icons` feature.
