# Vivid Icons

A file icon pack for Proteus. Every kind of file gets a Lucide icon in the color its language is known by: a cog for Rust, a moon for Lua, braces for JSON, a flask for tests. Folders most projects have, such as `src`, `tests`, `.git`, `docs` and `node_modules`, get icons of their own. Each color comes in two shades, a deeper one for light themes and a brighter one for dark themes, so the icons read on both.

Choose it with **View > Choose File Icons**, where the arrow keys preview each pack before you pick it, or set `icon_pack` to `vivid` in the settings. The Explorer, the Code Editor's file tree and the editor tabs all show it.

It gives a look to every kind of file Proteus knows, so it runs no code while you work, and it asks for no permissions. It needs a Proteus with the `icons` and `file-kinds` features.
