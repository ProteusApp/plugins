# Vivid Icons

A file icon pack for Proteus. Every kind of file gets a Lucide icon in the color its language is known by: a cog for Rust, a moon for Lua, braces for JSON, a flask for tests. Folders most projects have, such as `src`, `tests`, `.git`, `docs` and `node_modules`, get icons of their own.

Choose it with **View > Choose File Icons**, where the arrow keys preview each pack before you pick it, or set `icon_pack` to `vivid` in the settings. The Explorer, the Code Editor's file tree and the editor tabs all show it.

It adds its icons as file associations of the kind `icon`, so it runs no code while you work, and it asks for no permissions. It needs a Proteus with the `icons` feature.
