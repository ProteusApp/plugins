# Solarized themes

The precise, low-contrast Solarized colors, in a dark and a light theme.

It adds **Solarized Dark**, **Solarized Light** to Proteus. Choose one with **View > Choose Color Theme**, where the arrow keys preview each theme before you pick it, or set `theme` to `solarized-dark`, `solarized-light` in the settings.

The theme sets the colors of backgrounds, text, borders, the accent, problems, the selection, and the code editor's syntax. The terminal, diff and tag colors it leaves out come from the app's defaults for a dark or a light theme. It asks for no permissions.

Some colors are a shade darker or lighter than the original palette, so that text stands out from what it sits on as much as WCAG AA asks: 4.5 to 1 for text and code, 3 to 1 for faint text and status colors.
