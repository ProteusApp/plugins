# Gruvbox themes

Retro groove colors, warm and easy on the eyes, in a dark and a light theme.

It adds **Gruvbox Dark**, **Gruvbox Light** to Proteus. Choose one with **View > Choose Color Theme**, where the arrow keys preview each theme before you pick it, or set `theme` to `gruvbox-dark`, `gruvbox-light` in the settings.

The theme sets every color variable Proteus uses: backgrounds, text, borders, the accent, problems, the selection, and the code editor's syntax colors. It asks for no permissions.
