# Blueprint theme

White lines on Prussian blue drafting paper, with a measured grid behind the code.

An architect's blueprint: chalk-white lines on Prussian blue paper. The editor and the panels carry a drafting grid, a fine one every 8 pixels and a heavy one every 40, headings are lettered in capitals like a title block, and the accent is a yellow highlighter.

Choose it with **View > Choose Color Theme**, where the arrow keys preview each theme before you pick it, or set `theme` to `blueprint` in the settings. It sets every color variable Proteus uses, and adds CSS for the parts colors alone cannot draw. It asks for no permissions.
