# nanoqoi theme

A near-black theme in amethyst purples, from nanoqoi's Neovim colors.

It adds **nanoqoi** to Proteus. Choose it with **View > Choose Color Theme**, where the arrow keys preview each theme before you pick it, or set `theme` to `nanoqoi` in the settings.

The colors come from tokyonight's moon style with the Midnight Amethyst palette laid over it, the way nanoqoi's Neovim draws them. The theme sets the colors of backgrounds, text, borders, the accent, problems, the selection, and the code editor's syntax. The terminal, diff and tag colors it leaves out come from the app's defaults for a dark or a light theme. It asks for no permissions.
