# Bevel theme

A 1990s desktop: silver panels with raised and sunken bevels, and navy title bars.

A desktop from the mid 1990s. Silver panels with raised buttons and sunken fields, each bevel drawn from four one-pixel lines, panel headings as navy title bars, a navy highlight on whatever is selected, and chunky scroll bars on a dithered track.

Choose it with **View > Choose Color Theme**, where the arrow keys preview each theme before you pick it, or set `theme` to `bevel` in the settings. It sets every color variable Proteus uses, and adds CSS for the parts colors alone cannot draw. It asks for no permissions.
