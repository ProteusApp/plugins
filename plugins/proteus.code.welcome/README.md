# Welcome

What the Code Editor shows while no file is open. With no folder open, it is the Welcome page: open a folder, one of the folders opened before, a file, or a clone of a Git repository. With a folder open, it is the folder's page: its name, and the commands worth knowing, each with its key. Each gives way when a file opens, and comes back when the last tab closes.

It lists only the commands that are there and that it may run. Another plugin's command shows when that command is marked `shared`.

## Permissions

- `files` uses the `project` service, which names the open folder and the folders opened before.
