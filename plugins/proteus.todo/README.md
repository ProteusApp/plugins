# Todo

A to-do list on one screen. Install the **Todo** profile from the marketplace to run it as an app of its own.

It draws the whole window itself, with no menus, toolbar or layout, which shows that those plugins are optional. Its colours still come from the theme.

## What it does

- Type a thing to do and press Enter. Tick it when it is done.
- Double-click a thing to change it, or right-click it to edit, tick or delete it.
- Show all things, the ones left, or the ones done, and clear the done ones.
- Buttons at the bottom switch to another app and pick one of the builtin themes.

The list lives in `app.store`, so it survives a restart.

## Permissions

None.
