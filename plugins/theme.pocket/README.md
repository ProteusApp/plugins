# Pocket theme

The four greens of an early handheld game screen, with square corners, pixel shadows and an LCD dot grid.

The screen of an early handheld game: four greens and nothing else, from the darkest ink to the lightest glass. Corners are square, shadows are hard pixel steps, icons snap to the pixel grid, and a faint dot matrix lies over everything like the LCD.

Choose it with **View > Choose Color Theme**, where the arrow keys preview each theme before you pick it, or set `theme` to `pocket` in the settings. It sets every color variable Proteus uses, and adds CSS for the parts colors alone cannot draw. It asks for no permissions.

Some colors are a shade darker or lighter than the original palette, so that text stands out from what it sits on as much as WCAG AA asks: 4.5 to 1 for text and code, 3 to 1 for faint text and status colors.
