# Catppuccin themes

Soothing pastel themes: Mocha, which is dark, and Latte, which is light.

It adds **Catppuccin Mocha**, **Catppuccin Latte** to Proteus. Choose one with **View > Choose Color Theme**, where the arrow keys preview each theme before you pick it, or set `theme` to `catppuccin-mocha`, `catppuccin-latte` in the settings.

The theme sets every color variable Proteus uses: backgrounds, text, borders, the accent, problems, the selection, and the code editor's syntax colors. It asks for no permissions.
