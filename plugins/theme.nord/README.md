# Nord theme

An arctic, north-bluish dark theme, from the Nord palette.

It adds **Nord** to Proteus. Choose it with **View > Choose Color Theme**, where the arrow keys preview each theme before you pick it, or set `theme` to `nord` in the settings.

The theme sets every color variable Proteus uses: backgrounds, text, borders, the accent, problems, the selection, and the code editor's syntax colors. It asks for no permissions.
