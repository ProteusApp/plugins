# Outrun theme

Synthwave neon on a midnight purple sky, with a glowing grid running to the horizon under the code.

Synthwave after dark. Hot pink and electric cyan glow on a midnight purple sky, a sunset stripe runs under the menu bar, and a neon grid runs to the horizon under the code.

Choose it with **View > Choose Color Theme**, where the arrow keys preview each theme before you pick it, or set `theme` to `outrun` in the settings. It sets every color variable Proteus uses, and adds CSS for the parts colors alone cannot draw. It asks for no permissions.
