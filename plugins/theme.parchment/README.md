# Parchment theme

Iron-gall ink on warm paper, with book type, rubric red and a ruled margin beside the code.

A scholar's manuscript. Iron-gall ink on warm, faintly mottled paper, headings in book type and small capitals, rubric red for keywords, and a red margin rule beside the line numbers, as in a ruled notebook.

Choose it with **View > Choose Color Theme**, where the arrow keys preview each theme before you pick it, or set `theme` to `parchment` in the settings. It sets every color variable Proteus uses, and adds CSS for the parts colors alone cannot draw. It asks for no permissions.
